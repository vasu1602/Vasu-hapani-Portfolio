# Vasu Hapani — Frontend Engineer Portfolio

An ultra-modern, interactive **Frontend Engineer Portfolio** engineered with clean HTML5, CSS3, and JavaScript, featuring an interactive canvas physics arena, multi-theme preset engine, and real-world project showcases.

---

## 🌟 Key Highlights & Features

- **🎈 Interactive Skills Physics Arena**: Custom HTML5 Canvas physics engine with buoyant badges, fluid mouse repulsion, click shockwaves, and infinite horizontal looping.
- **🎨 Multi-Theme Color Engine**: 5 curated palettes including *Cyberpunk Neo-Tokyo*, *Emerald Matrix*, *Cosmic Sunset Rose*, *Midnight Obsidian*, and *Frosted Alpine Light*.
- **⚡ Next-Gen 2026 Studio UI**: Linear & Vercel-inspired dark luxe aesthetic, high-contrast snow-white CTAs, hairline specular border highlights, and real-time cursor spotlights.
- **🚀 Featured Web Projects**:
  - **Luxury Car Rental Platform**: Production web application built with React.js, Tailwind, Node.js, Express, JWT, and Firebase Storage.
  - **Unused Medicine Donation Platform**: Community health application connecting donors with NGOs built with HTML5, CSS3, JS, and MongoDB.
- **📄 Interactive Resume Modal**: In-browser modal viewer with quick print functionality.
- **📱 100% Responsive**: Tailored for desktops, tablets, and mobile viewports.

---

## 🛠️ Core Frontend Tech Stack

- **Frameworks & Core**: React.js, Next.js, TypeScript, JavaScript (ES6+)
- **Styling & Layout**: Tailwind CSS, Bootstrap, Modern CSS3 (Design Tokens, Grid, Flexbox)
- **Graphics & Physics**: HTML5 Canvas 2D API
- **Tools & Workflow**: Git & GitHub, Agile Development

## 🚀 Getting Started

To run this portfolio locally on your machine:

1. **Clone the repository**:
   `ash
   git clone https://github.com/vasu1602/Vasu-hapani-Portfolio.git
   cd Vasu-hapani-Portfolio
   `

2. **Open in Browser**:
   - Simply open index.html in your favorite web browser.
   - Or run a local HTTP server:
     `ash
     npx serve .
     # or
     python -m http.server 3000
     `
